## Overview

**Food & Health Nutrition Analytics** is a data analytics project that uses **MySQL, SQL, and Power BI** to analyze food nutrition, dietary information, and relationships between foods and health conditions.

The project transforms structured nutrition data into meaningful analytical insights and presents them through an interactive Power BI dashboard.

## Project Objectives

* Analyze nutritional values of different food items.
* Compare calories, protein, carbohydrates, fiber, fat, and other nutrients.
* Analyze food categories and nutritional patterns.
* Study relationships between foods and health conditions.
* Identify suitable foods based on nutritional and health-related criteria.
* Apply SQL concepts such as joins, aggregations, CTEs, and window functions.
* Build an interactive Power BI dashboard to visualize the analysis.

## Power BI Dashboard

The project includes three Power BI dashboard pages:

### 1. Executive Overview

Provides a high-level overview of the food and nutrition dataset, including important nutritional metrics and category-level insights.

### 2. Nutrition Explorer

Provides detailed analysis of nutritional values across different food items and categories, helping explore calories, protein, fiber, fat, and other nutrients.

### 3. Health Condition Analysis

Analyzes the relationship between food items and health conditions using suitability and nutrition-related information.
